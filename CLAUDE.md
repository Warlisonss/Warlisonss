# Instruções para o Claude

Ao criar, revisar ou preparar para distribuição/venda qualquer projeto de software, compare o projeto com `CHECKLIST-JURIDICO.md` e reporte item a item: conforme, não conforme ou não verificado.

- Dados de clientes e de terceiros não podem vazar nem ser acessados sem autorização. Trate qualquer falha nisso como bloqueante.
- Para a revisão, use as skills disponíveis que se aplicam (por exemplo `security-review`, `engineering:code-review`, `operations:compliance-tracking`, `operations:risk-assessment`) e diga quais usou.
- Não declare o projeto "em conformidade". Diga o que foi verificado e o que exige advogado.
